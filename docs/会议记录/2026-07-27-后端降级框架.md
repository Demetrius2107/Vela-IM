## 本次完成工作

### 1. 服务降级统一框架（ServiceDegradationManager）

| 文件/模块 | 改动说明 |
|-----------|----------|
| `.../utils/ServiceDegradationManager.java` | **新建** — 简易熔断模式，追踪 Redis/MQ 健康状态，连续失败 3 次 → DEGRADED，30s 冷却后通过探针自动恢复 |
| `.../message/.../MessageStoreService.java` | `storeP2PMessage`/`storeGroupMessage` 接入 MQ 降级检测；`storeOfflineMessage` 接入 Redis 降级检测 |

### 2. 接入的降级路径

| 路径 | 降级行为 |
|------|----------|
| `storeP2PMessage` MQ 发送 | MQ 降级时跳过 MQ，直接同步写 DB + 补偿队列 |
| `storeGroupMessage` MQ 发送 | MQ 降级时跳过 MQ，直接同步写 DB + 补偿队列 |
| `storeOfflineMessage` Redis ZSet | Redis 降级时直接写 DB message_history 表 |
