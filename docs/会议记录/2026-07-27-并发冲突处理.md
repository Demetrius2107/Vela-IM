### 2. MessageLockManager + 代码接入

| 文件/模块 | 改动说明 |
|-----------|----------|
| `.../utils/MessageLockManager.java` | **新建** — 基于 messageKey 的 ReentrantReadWriteLock 管理器。写锁=撤回(独占)，读锁=推送(共享) |
| `.../message/.../MessageSyncService.java` | `recallMessage` 写锁替代旧 synchronized，阻止推送/已读与撤回并发 |
| `.../pipeline/node/PersistAndPushNode.java` | 推送前获取读锁，超时则跳过推送走离线流程（recall 正在进行） |
| `.../test/.../MessageSyncServiceTest.java` | 适配新构造参数 MessageLockManager |
| `.../test/.../P2PMessageServiceTest.java` | 适配 PersistAndPushNode 新构造参数 |

### 3. 冲突场景覆盖

| 场景 | 处理方式 |
|------|----------|
| 撤回 ↔ 推送同时发生 | PersistAndPushNode 获取读锁，recallMessage 获取写锁 → 互斥 |
| 多端重复撤回 | 写锁互斥，只有一个能获取；已撤回的消息返回 `MESSAGE_IS_RECALLED` |
| 撤回 ↔ 已读 | readMark 无 messageKey（按 sequence 范围操作），维持原逻辑 |
