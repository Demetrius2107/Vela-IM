## Phase 1 — 消息功能增强

> 预计工时：1.5 ~ 2 周

| 优先级 | 功能 | 预估 | 难度 | 说明 |
|------|------|----|----|------|
| 🔴 P0 | **消息引用回复** | 2 天 | ⭐ | 回复时携带原消息 ID + 摘要文本，聊天气泡展示引用关系 |
| 🔴 P0 | **消息转发** | 2 天 | ⭐⭐ | 选择消息 → 选择目标会话 → 发送（含转发标记） |
| 🔴 P0 | **@提及** | 1 天 | ⭐ | 解析 @语法 → 存储 @关系 → 推送 @通知 |
| 🔴 P0 | **群公告** | 2 天 | ⭐⭐ | 公告 CRUD + 已读统计 + 新公告群通知 |
| 🔴 P0 | **表情/贴纸** | 1.5 天 | ⭐ | 表情选择器 + 常用表情 + 贴纸管理 |
| 🟡 P1 | **合并转发** | 2-3 天 | ⭐⭐⭐ | 多条消息合成转发卡片，支持展开查看原文 |
| 🟡 P1 | **消息搜索** | 3-5 天 | ⭐⭐⭐ | Elasticsearch 全文检索 + 搜索结果预览 |
| 🟡 P1 | **消息收藏** | 2 天 | ⭐⭐ | 收藏 CRUD + 收藏夹管理 + 跨端同步 |
| 🟢 P2 | **编辑已发消息** | 2 天 | ⭐⭐ | 消息编辑后显示"已编辑"标记 |
| 🟢 P2 | **定时发送** | 2 天 | ⭐⭐ | 指定时间发送消息，定时任务触发 |
| 🟢 P2 | **置顶消息** | 1 天 | ⭐ | 群聊/单聊消息置顶到会话顶部 |
| 🟢 P2 | **阅后即焚** | 2 天 | ⭐⭐⭐ | 消息阅读后自动删除（需客户端配合）|
