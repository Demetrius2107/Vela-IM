# Bot 模块深挖待办清单

> 版本: v1.0 | 创建时间: 2026-07-27
> 基于 Telegram Bot API 对标分析

---

## 当前状态

✅ 已实现：注册/管理/指令解析(/help/ping/echo)/Webhook回复/启用禁用/API密钥

---

## 🔴 P0 — 核心缺失

| 功能 | 说明 | 预估 |
|------|------|----|
| **回复富文本** | 当前只能回纯文本，需支持 Markdown、HTML 格式的消息 | 1 天 |
| **图片/文件回复** | Bot 可以回复图片、文件、语音等多媒体消息（复用 FileStorageService）| 2 天 |
| **群聊 Bot** | Bot 加入群聊、@bot 触发、群内指令 | 2 天 |
| **长轮询（Polling）** | 除了 Webhook，提供 /getUpdates 长轮询方式获取消息 | 2 天 |
| **速率限制** | 每条 Bot 消息间隔 N 秒，防止 Bot 刷屏 | 1 天 |

## 🟡 P1 — 体验增强

| 功能 | 说明 | 预估 |
|------|------|----|
| **内联键盘（Inline Keyboard）** | 回复消息中带按钮，点击按钮触发回调 | 3 天 |
| **行内查询（Inline Query）** | 在输入框输入 @bot query 时 Bot 实时返回建议 | 3 天 |
| **Bot 权限系统** | 群 Bot 的读写权限、管理员/成员权限分级 | 2 天 |
| **Bot 市场/发现** | Bot 列表、搜索、安装到群 | 2 天 |
| **Bot 统计** | 每个 Bot 的消息量、用户数、响应时间 | 1 天 |

## 🟢 P2 — 高级特性

| 功能 | 说明 | 预估 |
|------|------|----|
| **Bot SDK（Java）** | 提供 Java SDK 让开发者 5 行代码写一个 Bot | 3 天 |
| **Bot 定时任务** | Bot 可以设置定时推送（每日天气、新闻等）| 2 天 |
| **Bot 支付** | 内购、打赏、订阅付费 | 复杂 |
| **Bot 游戏** | HTML5 游戏嵌入 Bot 消息 | 复杂 |

---

## 完成标准

1. Bot 能发文字/图片/文件/按钮消息
2. Bot 能在群里被 @ 触发
3. Bot 能通过轮询或 Webhook 接收消息
4. 用户能通过 Bot 市场发现和安装 Bot
5. 第三方开发者能用 SDK 写 Bot
